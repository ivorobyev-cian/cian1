# Бренд-профиль мобильного прототипа

Токены взяты из `styles.css`: синий `#0468ff`, оранжевый `#ff7a26`, текст `#152242` и нейтральные поверхности. В репозитории нет локального шрифта продукта, поэтому используется Manrope из шаблона product-motion (SIL Open Font License 1.1, текст лицензии лежит в `fonts/Manrope-OFL.txt`).
